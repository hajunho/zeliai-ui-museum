# 🏛 ZeliAI UI Museum

AI 포털 **젤리아이(ZeliAI)** 가 거쳐온 UI들을 보존하는 디자인 히스토리 아카이브입니다.

A small design-history museum preserving the user interfaces of **ZeliAI**, the Korean AI portal by YEJIN Co., Ltd.

## 이 저장소에 대해 (About)

- 모든 전시물은 **정적 HTML 한 장짜리 "껍데기(shell)"** 입니다 — 실제 서비스 코드(React)가 아니며,
  API 호출·데이터·계정 정보·연락처가 전혀 포함되어 있지 않습니다. 버튼을 누르면 "전시물입니다"라고 답합니다.
- 각 화면은 당시 실서비스의 레이아웃·색·문구를 바탕으로 한 **재현본(recreation)** 으로, 실물과 세부가 다를 수 있습니다.
- 외부 리소스(CDN·폰트·이미지) 의존이 없어 오프라인에서도 열립니다.

All exhibits are single-file static HTML shells: no APIs, no data, no credentials — recreations for
design-history purposes only, and may differ from the production service in details.
